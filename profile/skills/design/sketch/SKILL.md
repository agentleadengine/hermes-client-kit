# Sketch

For a requested dashboard, describe one screen in plain words: its title, key numbers, main list, primary action, and mobile layout. Read the Business Brief before using business facts. Ask the owner to check the sketch before any build or publish step. A sketch is guidance, not permission to enable Builder or publish.
